  • 조선 연표 1876 → 1884 → 1894 → 1896 → 1897 → 1905 → 1910을 순서대로 쓸 수 있다
  • 러시아 혁명을 3월 혁명 / 11월 혁명으로 답한다 (2월·10월로 쓰면 오답)
