## 문항 구성

XML: `drafts/question-bank/english/ENG2S2_questions.xml`

- 총 150문항
- 1~4차: 각 30문항 (총 120)
- 예비: 30문항
- 각 회차: 객관식 25 + 서술형 5
- 전체: 객관식 125 + 서술형 25
- 각 문항: 과목, 학교급, 학년, 학기, 범위, 난이도, 난이도2, 단원, 개념, 발문, 보기, 정답, 해설, 심화해설, 풀이 인원, 정답 인원, 정답률 통계 필드 포함
- 통계는 풀이 전 0명 / 정답률 미산정
- 지문은 7과 주제에 맞춰 새로 작성한 4개 지문만 사용
- 8과는 단어·숙어와 문법 문항만 출제하고 passageRef를 두지 않음

## 출제 방식

- 어휘 문맥 빈칸, 단어·숙어 의미 및 용법
- 현재완료의 형태와 경험/계속 의미
- It 가주어·가목적어와 to부정사
- call A B 및 목적어+목적격 보어
- 간접의문문 어순
- because + 절 / because of + 명사(구)
- 7과 지문 중심 내용, 세부 정보, 지시어, 순서, 추론, 제목, 글의 목적
- 조건형 서술·문장 변형·어순 배열
- 난이도는 회차가 진행될수록 적용·추론 요소를 높임

## 시험 화면 구현

- `scripts/english_exam.js`: 영어 전용 시험 로직
- `index.html`: 영어 탭 활성화 및 영어 시험 패널 연결
- 국어 시험의 XML, FINAL, 풀이 기록, 회차 해금/오답 재출제 코드는 수정하지 않음.
- 영어 풀이 기록은 `study_daily_han_english_round_results_v1` 별도 키에 저장.
- 1~4차는 직전 회차 오답을 우선 포함하고 신규 문항으로 30문항을 채움.
- 영어 FINAL은 문제은행에서 객관식 23 + 서술형 3을 선택하여 별도 풀이.
- FINAL은 기존 국어 FINAL 파일이나 기록과 공유하지 않음.
