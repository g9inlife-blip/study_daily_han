## 1. 작업 목적

중학교 2학년 2학기 국어 기말고사 대비 문제은행 150문항을 검토하고, XML 데이터 형식으로 Git 저장소에 보관한다.

문제은행은 추후 네트워크 기반 학습시스템 및 DB로 확장할 것을 고려하여 문항 정보와 학습 통계 필드를 분리해 유지한다.

이번 작업에서는 기존 일일 학습 시스템의 데이터와 로더를 변경하지 않는다. 새 문제은행은 별도 초안 경로에 보관한다.

## 3. 문항 데이터 필드 원칙

모든 문항은 다음 정보를 기본으로 관리한다.

| 필드 | 설명 |

현재 파일의 통계 필드는 풀이 이력 축적 전 초기값이다. 실제 서비스에서는 풀이 인원과 정답 인원을 기반으로 정답률을 산정하고 난이도2를 갱신한다.

> 난이도2는 생성 단계에서 임의로 채우지 않는다. 충분한 응답 수와 통계 기준을 마련한 뒤 산정한다.

### 4.3 발견된 품질 문제

**현재 문제은행은 교육적 품질 검수를 통과하지 못했다.**

1. 동일한 지문이 반복된다. 최종 재검사에서는 중복 지문 인스턴스 72건, 중복 지문 그룹 52개가 확인되었다.
2. 주관식 25문항은 질문이 요구하는 답과 실제 모범답안이 일치하는지 전수 재검토가 필요하다. 자동 문자열 비교에 따른 의심 표시이므로 25건 모두를 확정 오류라고 단정하지는 않는다.
3. 심화해설이 정답 설명을 반복하는 경향이 있다. 선택지별 오답 원인, 지문 근거, 오개념 교정, 적용 학습이 부족하다.
4. 문항의 상황 설정이 실제 평가 개념과 긴밀하게 연결되지 않는 사례가 있다.
5. 조사 호응 등 문장 교정이 필요하다.
6. 예비 문항도 본문 문항과 지문·개념·정답 구조가 중복되는 사례가 있다.

### 4.4 검수 판정

- XML 구조: 통과
- 기본 필드 및 보기 구조: 통과
- 문항 독립성: 미통과
- 주관식 정답 타당성: 재검토 필요
- 심화해설 품질: 미통과
- 교육과정 및 교과서 범위 적합성: 문항별 대조 필요
- 상용 서비스 반영: 보류

따라서 현재 파일은 **검수용 초안**으로만 취급한다. 학습자에게 노출하거나 운영 서비스에 반영하지 않는다.

## 5. 저장소 호환성 검토

현재 저장소의 일일 학습 앱은 다음 구조를 사용한다.

- 루트: `<daily>`
- 문항 컨테이너: `<questions>`
- 문항 요소: `<q>`
- 객관식: 4지선다 구조

이번 문제은행은 다음 구조다.

- 루트: `<examBank>`
- 문항 요소: `<question>`
- 객관식: 5지선다 포함

따라서 기존 일일 학습 데이터 폴더나 `manifest.json`에 바로 등록하지 않는다. 별도의 문제은행 데이터 모델과 로더 호환성 검토가 선행되어야 한다.
