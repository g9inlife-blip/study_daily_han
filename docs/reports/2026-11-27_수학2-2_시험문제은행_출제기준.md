## 시험 범위
- 과목: 수학
- 학교급/학년: 중학교 2학년, 2학기
- 교과서: 천재교육 중학교 수학 2-2
- 전체 범위: 184~249쪽
- Ⅴ 도형의 닮음과 피타고라스 정리 + Ⅵ 확률
- Ⅴ-1 도형의 닮음 184~206쪽 전부
  - 닮음의 뜻·성질, 삼각형의 닮음 조건, 평행선과 선분의 비, 중점연결정리, 삼각형의 무게중심
- Ⅴ-2 피타고라스 정리 207~218쪽 제외
- 219쪽은 사용자가 ‘대단원 마무리로 추정, 미확인’이라고 안내하여 범위 확정 전 출제하지 않음
- 220쪽 7~11번 유형 포함, 12번 제외
- 221쪽 14·15번 유형(서술형) 포함, 13·16번 제외
- Ⅵ 확률 226~249쪽
  - 경우의 수, 합의 법칙·곱의 법칙, 대표 선택, 수학적 확률, 확률의 범위, 여사건, 확률의 계산, 동시·연속 시행
- 249쪽 13~16번 유형 포함(13번 선택형, 14~16번 서술형 형식)
- 실제 교과서 문제를 그대로 복제하지 않고, 문제 항목 이미지에서 확인한 단원/유형/문항 형식에 맞춰 새 문항으로 구성

## 문제은행 구성
- XML: `drafts/question-bank/math/MATH2S2_questions.xml`
- 총 150문항
- 1~4차 각 30문항(120문항) + 예비 30문항
- 각 회차 객관식 25문항 + 서술형 5문항
- 전체 객관식 125문항 + 서술형 25문항
- 필수 항목: 과목, 학교급, 학년, 학기, 단원, 페이지 범위, 난이도, 난이도2, 개념, 발문, 보기, 정답, 해설, 심화해설, 풀이/정답 통계
- 난이도2 및 정답률은 통계가 쌓이기 전 ‘미산정’, 풀이 인원·정답 인원은 0
- 1차 기본 개념·계산, 2차 적용, 3차 조건 분석, 4차 종합 응용
- 피타고라스 정리 문항은 출제하지 않음

## 화면 적용
- `index.html`: 수학 과목 탭 활성화, 수학 시험 패널 및 도형 이미지 CSS 추가
- `scripts/math_exam.js`: 수학 문제은행 로드, 회차 카드, 문항 렌더링, SVG 표시, 채점, 오답 반영, FINAL, 수학 전용 풀이 기록 구현
- 영어 시험 화면과 수학 화면이 동시에 보이지 않도록 과목 전환 처리
- 수학 풀이 기록은 `study_daily_han_math_round_results_v1`, FINAL은 `study_daily_han_math_final_results_v1` 별도 키 사용
- 국어 시험의 문제은행, FINAL, 해금·오답 재출제 로직은 수정하지 않음
