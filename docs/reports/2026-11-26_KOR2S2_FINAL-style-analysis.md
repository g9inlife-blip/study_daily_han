## 1. 확인 상태와 제한

GitHub 저장소의 지정 경로에서 2025 기출 PDF 파일을 확인했다. 파일 조회 결과 PDF 시그니처(`%PDF`)가 확인되어 PDF 바이너리임을 확인했다.

다만 현재 연결된 GitHub 파일 조회는 PDF를 base64 형태로 반환하며, 이 세션의 연결 도구에서는 해당 바이너리를 페이지별 이미지 또는 텍스트로 변환해 판독할 수 없었다. 프로젝트 파일 검색에서도 2025 기출 PDF의 별도 인덱싱본은 확인되지 않았다.

따라서 아래 항목은 **실제 PDF 판독 전 미확정**이다. 문항 수, 총점, 문항별 배점, 객관식·서술형 비율, 지문 구성, 발문 스타일을 추정값으로 채우지 않는다. 실제로 확인하지 않은 기출 스타일을 확인했다고 기록하지 않는다.

## 2. FINAL 제작의 확정 원칙

1. FINAL은 1~4차의 오답 문항을 재출제하는 회차가 아니다.
2. FINAL 전용 문제 XML과 FINAL 전용 회차 구성을 별도 경로에 둔다.
3. FINAL 전용 문항은 1~4차 및 일반 복습 회차에서 사용하지 않는다.
4. 2025 기출은 출제 형식과 출제자 스타일을 분석하는 참고자료로만 활용한다.
5. 2025 기출의 문항·지문·정답을 그대로 사용하지 않고, 2026년 교과서 시험범위에 맞춘 새 문항을 제작한다.
6. 2025년 기출 시험범위가 현재 시험범위와 다르면, 기출의 내용 요소는 배제하고 형식적 특징만 참고한다.
7. FINAL 전체는 한 가지 출제자 스타일로 일관되게 구성한다. 서로 다른 시험 스타일을 임의로 혼합하지 않는다.
8. 배점 합계, 문항 수, 문항 유형 분포가 확인된 기출 형식과 맞는지 검증한다.

### 배점 검증 규칙

- 문항별 배점 합계가 시험지 총점과 일치해야 한다.
- 문항 수와 유형별 개수의 합이 전체 문항 수와 일치해야 한다.
- 배점이 복수 문항에 걸쳐 표기된 경우 문항별 배점으로 오인하지 않도록 한다.
- 서술형의 부분점수는 원문에 채점기준이 있는 경우에만 참고한다. FINAL 자체의 채점기준은 별도로 작성한다.

## 5. 단일 출제자 스타일 적용 기준

실제 기출 판독 후 가장 일관되게 나타나는 특징을 하나의 스타일 프로파일로 정리한다. 프로파일은 아래 항목으로 구성한다.

- 지문 길이와 문체
- 자료 제시 방식과 지문·보기 결합 방식
- 발문 문장 구조
- 선택지 길이와 표현 수준
- 오답 선택지의 설계 방식
- 단순 개념 확인과 상황 적용의 비중
- 서술형 답안에 요구하는 핵심 요소
- 문항별 배점과 답안 작성 부담의 관계

FINAL 제작자는 이 프로파일을 전체 문항에 일관되게 적용한다. 특정 문항만 다른 교재나 모의고사 스타일로 튀지 않도록 최종 편집 단계에서 통일성을 검수한다.

## 6. FINAL 문항 설계 원칙

- 교과서 개념을 정확히 이해했는지 확인하는 문항과, 낯선 자료·상황에 적용하는 문항을 함께 둔다.
- 교과서의 핵심 개념을 단순히 문장만 바꿔 반복하지 않는다.
- 복합 자료 문항은 자료의 내용과 질문의 정답 근거가 직접 연결되도록 한다.
- 오답 선택지는 교과 개념의 혼동이나 자료 해석 오류를 반영하되, 지문만으로 정답이 유일하게 결정되도록 한다.
- 서술형은 배점에 맞는 답안 길이와 핵심 채점 요소를 제시한다.
- 심화해설에는 정답 근거뿐 아니라 각 오답이 왜 틀렸는지, 어떤 개념을 혼동했는지 포함한다.
- 문제 원본 XML에 과목, 학교급, 학년, 범위, 생성 난이도, 통계 난이도, 문제, 정답, 해설, 심화해설, 풀이 인원, 정답 인원 필드를 유지한다.
- 실제 풀이 통계가 없는 통계 난이도는 미산정으로 둔다.

## 7. 권장 FINAL 데이터 분리

```
drafts/question-bank/
├── rebuild/                 # 기존 단원별 문제 풀 150문항
├── final/
│   ├── KOR2S2_FINAL_questions.xml
│   └── KOR2S2_FINAL_exam.xml
└── sessions/
    └── KOR2S2/
        ├── round1.xml
        ├── round2.xml
        ├── round3.xml
        └── round4.xml
```

- `KOR2S2_FINAL_questions.xml`: FINAL 전용 신규 문항 원본
- `KOR2S2_FINAL_exam.xml`: 문항 ID, 출제 순서, 배점, 문항 유형을 연결하는 FINAL 시험지
- FINAL 문항 ID는 일반 문제 풀 ID와 구분되는 `KOR2S2-FINAL-` 접두사를 권장한다.
- 위 경로는 설계안이며 기존 앱 데이터 로더나 manifest에 연결하지 않는다.

## 10. 사용자 확정 회차 정책

- 1차: 전체 시험범위 통합 출제

- 3차: 2차 오답 + 신규 문항
- 4차: 3차 오답 + 신규 문항
