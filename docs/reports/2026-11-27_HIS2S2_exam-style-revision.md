- 범위 정리: `docs/교과서/역사정리.txt`

## 기출 형식 분석
2025학년도 기말고사는 총 29문항, 총점 30점 구성이다.
- 선택형 24문항은 각 1점, 5문항은 각 1.2점으로 배점했다.
- 단순 용어 정의만 묻기보다 사료·대화·기사·연표·도식·표를 읽고 역사적 맥락을 판단하게 했다.
- ㄱ·ㄴ·ㄷ·ㄹ 진술의 참·거짓을 판별한 뒤 조합을 고르는 문항이 반복적으로 등장했다.
- 사건의 순서·전후 관계, 인물과 활동의 연결, 빈칸 추론, 특정 자료가 가리키는 사건, 결과·영향의 판단, 옳지 않은 설명 고르기 유형을 섞었다.
- 하나의 자료를 제시하고 연속 문항으로 서로 다른 측면을 묻는 세트형 구성이 있었다.
- 오답은 완전히 무관한 단어보다 시기·인물·국가·원인과 결과를 바꾸어 놓아, 개념을 정확히 구분해야 풀 수 있게 했다.

※ 작년 기출의 역사 범위는 이번 시험 범위와 다르므로, 사실·문항을 가져오지 않고 난이도와 출제 형식만 참고한다.

## 기존 문제은행 처리 원칙
기존 `HIS2S2_questions.xml`의 문항은 개념 확인형·단답 암기형 비중이 높고, 심화해설도 선택지별 역사적 근거가 충분하지 않다. 기존 문항을 새 출제본의 문항으로 재사용하지 않는다. 새 문항 검수 완료 후 기존본은 별도 보관본으로 남기고, 앱이 읽는 기본 문제은행은 새 문항으로 교체한다.

## 새 출제 기준
1. 1~4차 각 30문항, FINAL은 26문항으로 구성한다. 1~4차 간 동일 문항 재사용을 금지한다.
2. 5지선다형을 기본으로 하되, 아래 유형을 균형 있게 섞는다.
   - ㄱ·ㄴ·ㄷ·ㄹ 복수 진술 조합형
   - 연표·사건 순서 및 선후 관계
   - 사료·기사·대화·상황 자료 해석형
   - 표·도식·지도 정보 판단형(실제 자료가 필요한 경우에만 자료를 함께 제공)
   - 인물·국가·사건·정책 연결형
   - 원인과 결과, 배경과 영향 추론형
   - 빈칸·옳은 것/옳지 않은 것 판단형
   - 공통 자료를 이용한 연속 문항 세트형
3. 단순 연도 암기보다 주체·목적·배경·전개·결과를 연결해야 정답을 고를 수 있게 한다.
4. 난이도는 하 비중을 줄이고 중·상 중심으로 구성한다. 난이도(difficulty)는 출제 시 판단값, 난이도2(difficulty2)는 실제 풀이 통계가 쌓인 뒤 산출값으로 구분한다.
5. 정답 해설은 정답의 역사적 근거를 설명한다. 심화해설은 ㄱ~ㄹ 각각과 모든 오답 선택지가 왜 맞거나 틀리는지, 혼동하기 쉬운 사건·인물·시기를 구체적으로 비교한다.
6. 범위 밖 지식이 없어도 풀 수 있도록 하며, 이번 범위(163~165, 177~208, 216~222쪽)에서 시험에 출제될 만한 핵심 사실과 자료 해석을 우선한다.
7. 기본 데이터 필드(과목, 학교급, 학년, 범위, 난이도, 난이도2, 문제, 정답, 해설, 심화해설, 문제푼인원수, 정답인원수)를 유지하고 XML로 저장한다.
