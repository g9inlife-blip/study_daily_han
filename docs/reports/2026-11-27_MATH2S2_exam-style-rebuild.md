기출의 특징을 반영했다.

- 닮음 도형의 대응 관계와 조건 판별
- 평행선으로 나뉜 선분의 비례식
- 중점연결정리 및 역, 무게중심의 선분·넓이 관계
- 그림이나 상황의 조건을 먼저 해석한 뒤 여러 단계로 계산
- 경우의 수에서 선택의 순서·중복 여부·직책 구분
- 주사위, 카드, 조사 결과, 복원/비복원 추출을 이용한 확률

기출 문항을 그대로 복제하지 않고 동일한 학습 목표의 새로운 수치와 상황으로 작성했다.

## 재구성 결과

`drafts/question-bank/math/MATH2S2_questions.xml`의 주 문제 120문항을 재작성했다.

- 각 원천 그룹 30문항: 객관식 25, 서술형 5
- 각 원천 그룹의 난이도: 중 6, 중상 11, 상 13
- 총 난이도: 중 24, 중상 44, 상 52
- 문제 유형: 단순 공식 대입만 반복하지 않도록 조건 해석, 역산, 대응 관계, 두 단계 이상 계산, 배열 조건, 확률 상황 해석을 포함
- 정답 위치와 선택지의 중복 여부를 정적 검사

기존 30문항 예비 문제는 보존했다. 정규 1~4차와 FINAL은 주 문제은행 120문항을 사용한다.

## 시험 차수 구성 원칙

1~4차는 범위별 시험이 아니다. `stage="1"~"4"`는 문제 제작·분류를 위한 원천 그룹이다.

- 각 회차는 주 문제은행 120문항 전체에서 30문항을 무작위 조합
- 직전 회차 오답을 우선 복습 문항으로 포함
- 직전 회차 정답 문항은 다음 회차의 신규 조합에서 제외
- 모든 회차에 도형의 닮음과 확률 영역이 함께 포함될 수 있음

## 범위 및 제외 조건

유지한 수학 범위와 제외 조건:

- 포함: Ⅴ-1 도형의 닮음 184~206쪽
- 포함: Ⅵ 확률 226~249쪽
- 제외: 207~218쪽, 219쪽(범위 확인 전 제외)
- 제외: 220쪽 12번, 221쪽 13번·16번

## 정적 검수

- 주 문제 120문항, 예비 30문항
- 원천 그룹별 30문항
- 각 그룹 객관식 25·서술형 5
- 중복 문항 ID 0
- 객관식 정답 키 누락 0
- 객관식 선택지 중복 0
- 정답·해설·심화해설 누락 0
- 시험 로직의 차수별 범위 제한 제거 확인
- 직전 회차 오답 우선 및 정답 문항 제외 로직 확인

실제 브라우저에서 1~4차 시작·제출·채점까지 실행하는 테스트는 아직 수행하지 않았다. 정적 검수는 문항의 화면 렌더링과 모든 풀이의 의미적 완전 검증을 대체하지 않는다.
