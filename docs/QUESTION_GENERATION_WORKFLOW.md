# 월간 문제 배치 생성·검수 운영안

## 결론

**한 달치 기본 학습 데이터를 미리 배치 생성하고, 매일 생성은 하지 않는다.** 매일 그날그날 생성하면 문제 품질과 학습 시간의 일관성이 떨어지고, 접속 시 생성 지연 또는 생성 실패가 학습을 막을 수 있다.

권장 운영은 다음과 같다.

- 월간 기본 세트: 해당 월 평일 학습일 기준 약 20일분을 미리 생성
- 검수 단위: 5일씩 주간 묶음으로 생성·검수
- 보충 세트: 학습 결과에서 드러난 오답 개념만 주 1회 추가 생성
- 다음 월: 실제 학교 진도, 시험 범위, 최근 오답을 반영해 생성

## 1. 한 달 데이터의 규모

평일 20일을 기준으로 계산한다.

| 콘텐츠 | 하루 | 한 달(20일) |
|---|---:|---:|
| 집중 과목 문제 | 5문항 | 100문항 |
| 영어 단어 | 2개 | 40개 |
| 영어 숙어 | 2개 | 40개 |
| 일일 콘텐츠 파일 | 1개 | 20개 XML |

과목별로는 월~금 로테이션에 따라 대략 4회씩 학습한다. 공휴일이나 시험 일정이 있으면 해당 월의 실제 학습일을 기준으로 조정한다.

영어 집중일에도 영어 단어 2개와 숙어 2개는 별도로 제공하고, 집중 과목 문제 5개를 추가한다.

## 2. 권장 월간 생성 파이프라인

### 단계 A — 진도 확인 (월간 생성 전)

보호자가 다음 정보를 확인한다.

- 학년·학기
- 학교에서 현재 배우는 과목별 단원
- 교과서 출판사 또는 단원명(가능한 경우)
- 월간 시험 날짜와 범위
- 이미 완료한 단원과 아직 배우지 않은 단원
- 최근 점수와 오답 단원

학교 진도는 학교마다 다를 수 있으므로, 자동으로 추측해 확정하지 않는다. 진도 정보가 없으면 보호자 확인이 필요한 항목으로 표시하고, 해당 단원은 임시 계획으로 둔다.

### 단계 B — 월간 캘린더 작성

먼저 문제를 생성하지 않고 날짜·요일·과목·단원·학습 목표만 배치한다.

각 날짜는 다음 필드를 갖는다.

- 날짜, 요일, 과목
- 단원 및 소단원
- 학습 목표
- 선수 개념 또는 누적 복습 개념
- 문제 유형과 난이도 구성
- 시험 대비 여부

캘린더를 확인한 뒤 문제를 생성한다. 이렇게 하면 같은 단원만 반복되거나, 아직 배우지 않은 개념이 갑자기 등장하는 일을 줄일 수 있다.

### 단계 C — 1주 단위 생성

한 번에 20일을 전부 생성하기보다는 **5일씩 4회** 생성하는 것을 권장한다.

1. 월요일~금요일의 XML 5개 생성
2. 각 날짜의 5문항 및 영어 단어·숙어 생성
3. 정답과 해설을 별도로 재검토
4. 콘텐츠 검증 스크립트 실행
5. 보호자가 주간 세트를 확인
6. 문제가 있으면 수정한 후 다음 주 생성

월간 캘린더는 한 번에 만들되, 문제 본문은 주간 단위로 생성하는 방식이 품질과 작업 관리에 유리하다.

## 3. 과목별 문항 구성 규칙

### 공통

- 하루 5문항: 객관식 3 + 주관식 2
- 객관식은 정답 하나만 명확하게 존재하도록 작성
- 오답 선택지는 그럴듯하되, 문제의 조건과 해설을 통해 오답임이 설명되어야 함
- 모든 문항에 정답과 충분한 해설 포함
- 문제 난이도는 해당 학년·학교 진도에 맞추고, 고등학교/수능형 요소는 선수 개념이 준비된 경우에만 도입
- 같은 날짜 또는 월간 세트 내에서 동일한 문항·정답 패턴이 반복되지 않도록 검토

### 수학

객관식 3문항:
- 중간 난이도 2문항
- 높은 난이도 1문항

주관식 2문항:
- 기본 계산 또는 개념 적용 1문항
- 풀이 과정을 요구하는 서술형 1문항

높은 난이도 문항은 단순히 계산이 길거나 함정이 많은 문제로 만들지 않는다. 개념 연결, 조건 해석, 한 단계 이상의 추론을 요구한다.

### 국어

- 교과서 단원과 학습 목표에 맞춘 자체 제작 지문 또는 합법적으로 사용할 수 있는 자료
- 지문 이해, 어휘/표현, 문법, 근거 찾기, 서술형을 균형 있게 구성
- 지문을 사용하면 문제와 답이 지문에 근거해야 함
- 교과서 본문을 장문 그대로 복제하지 않는다.

### 영어

- 매일 단어 2개 + 숙어 2개
- 영어 집중일은 문법, 어휘, 짧은 독해, 문장 배열, 오류 수정, 문장 작성 등을 혼합
- 예문은 학습 수준에 맞춘 자체 작성 문장
- 단어·숙어는 최근 학습 항목과 중복되지 않도록 월간 목록에서 관리

### 과학

- 개념 확인, 현상 설명, 실험/표/그래프 해석을 혼합
- 변인과 결과, 관찰과 추론을 구분
- 계산 문제는 단위와 풀이를 검토

### 역사/사회

- 사실 확인뿐 아니라 배경·원인·결과·비교·자료 해석 포함
- 연도 암기만 반복하지 않음
- 사료나 자료를 사용하면 출처와 시대가 명확해야 함

## 4. 품질 검수 체크리스트

배치 생성 후 다음 항목을 반드시 확인한다.

- [ ] 날짜와 요일, 과목 로테이션이 맞는가?
- [ ] 해당 단원이 학교 진도와 맞는가?
- [ ] 문항 수와 객관식/주관식 비율이 맞는가?
- [ ] 수학 객관식 난이도가 중 2개 + 상 1개인가?
- [ ] 객관식 정답이 하나뿐이고 선택지 번호가 올바른가?
- [ ] 주관식 모범답안과 채점 포인트가 충분한가?
- [ ] 계산·사실·용어·단위가 정확한가?
- [ ] 해설이 정답을 실제로 설명하는가?
- [ ] 지문이나 자료의 저작권을 침해하지 않는가?
- [ ] 영어 단어 2개와 숙어 2개가 포함되었는가?
- [ ] 월간 세트에서 중복·유사 문항이 과도하지 않은가?
- [ ] XML 파싱 및 자동 검증을 통과하는가?

AI가 생성한 문제는 자동 생성만으로 확정하지 않는다. 문항의 오류나 모호한 선택지는 학습자가 잘못된 개념을 익히게 할 수 있으므로, 정답·해설과 함께 검수한다.

## 5. 생성 프롬프트 템플릿

월간 캘린더가 확정된 뒤, 주간 배치마다 다음 지시를 사용한다.

> `study_daily_han`의 기존 XML 형식과 manifest 규칙을 유지한다.
> 지정된 5개 학습일의 XML 파일을 생성한다.
> 각 날짜는 집중 과목 문제 5개(객관식 3, 주관식 2), 영어 단어 2개, 영어 숙어 2개를 포함한다.
> 수학 집중일은 객관식 중 난이도 2개와 상 난이도 1개를 포함한다.
> 각 문제는 학년과 지정 단원에 맞고, 정답과 상세 해설을 포함한다.
> 지문·예문은 자체 제작하며 교과서 본문을 그대로 복제하지 않는다.
> 날짜, 요일, 과목, 단원, 학습 목표는 아래 제공된 캘린더와 일치해야 한다.
> XML은 well-formed여야 하며, 기존 앱에서 읽을 수 있는 현재 스키마를 유지한다.
> 생성 후 문제 수, 답 번호, 정답, 해설, 단어/숙어 수를 자체 점검하고 검수 결과를 별도로 요약한다.

프롬프트에는 반드시 해당 주의 날짜·과목·단원·학습 목표를 첨부한다. 단순히 “중2 한 달 문제 만들어줘”라고 요청하면 진도와 문항 배치가 불안정해질 수 있다.

## 6. 저장 및 릴리스 규칙

- 각 날짜의 파일명은 `data/days/YYYY-MM-DD.xml`
- manifest에 날짜별 항목을 추가
- 문제 ID는 가능하면 날짜와 분리된 안정적인 ID를 사용
- 생성 후 `python tools/validate_content.py` 실행
- 검수 완료된 주간 세트만 main에 반영
- 이미 학습한 문제를 정답/내용 변경으로 수정하면 변경 내역을 기록

## 7. 실제 운영 권장 리듬

| 시점 | 작업 |
|---|---|
| 매월 마지막 주 | 다음 달 진도와 시험 범위 확인 |
| 월간 계획 작성 | 날짜·단원·학습 목표 배치 |
| 주간 생성 1~4회 | 5일치 문제 생성·검수 |
| 매주 말 | 오답/점수 확인, 보충 문제 소량 추가 |
| 월말 | 중복·난이도·진도 적합성 점검 후 다음 달 계획 |

**최종 판단:** 한 달치 기본 문제를 미리 만들어 두는 것이 맞다. 단, 20일 문제를 한 번의 거대한 생성 작업으로 만들기보다는 월간 캘린더를 먼저 확정하고 5일 단위로 생성·검수·커밋하는 것이 안전하다. 매일 생성은 보충 문제에만 사용한다.
