# 중2 2학기 국어 기말고사 시험 기능

작성일: 2026-11-26  
상태: 기능 요구사항 확정 / 실제 문항 데이터 생성 대기  
대상 저장소: `g9inlife-blip/study_daily_han`

## 1. 시험 범위

- 학년: 중학교 2학년
- 학기: 2학기
- 시험: 국어 기말고사
- 국어 A: 미래엔 교과서 166~199쪽 및 해당 범위 관련 활동지
- 국어 B: 교과서 70~119쪽 및 해당 범위 관련 활동지

※ 국어 B의 출판사/저자 판본은 활동지 또는 교과서 표지로 확인한다.  
※ 교과서와 활동지의 실제 내용 확인 전에는 단원명이나 문항 내용을 추정해 확정하지 않는다.

## 2. 화면 구조

기존 상위 탭을 다음과 같이 분리한다.

- 매일공부: 기존 날짜별 매일 5문제 기능을 유지한다.
- 시험: 시험 목록 및 시험 단계 화면을 제공한다.

시험 탭의 시험 카드:

**중학교 2학년 2학기 국어 기말고사**

시험 범위 요약:
- 국어 A 미래엔 166~199쪽 + 관련 활동지
- 국어 B 70~119쪽 + 관련 활동지

## 3. 문항 구성 및 사전 생성

- 4단계 시험
- 단계별 30문항
- 단계별 객관식 25문항
- 단계별 단답형 주관식 5문항
- 4단계 총 출제량: 120문항
- 사전 생성 문제은행: 150문항
- 각 단계는 문제은행에서 중복되지 않도록 30문항을 배정한다.
- 문제은행 중 30문항은 예비/교체 문항으로 보유한다.
- 실제 문항 데이터는 XML로 저장한다.

문항 배분 원칙:
- 국어 A와 국어 B의 범위 및 활동지 내용에 맞춰 균형 있게 출제한다.
- 같은 지문·같은 핵심 개념을 반복해 사실상 동일한 문제를 만들지 않는다.
- 객관식은 5지선다형을 기본으로 한다(학교 시험 형식이 다르면 수정).
- 주관식은 단답형으로 채점 기준/허용 답안을 XML에 포함한다.

## 4. 단계 잠금 및 진행 조건

- 최초에는 1단계만 열려 있다.
- 1단계 30문항을 모두 제출하고 결과가 저장되면 2단계가 열린다.
- 2단계는 1단계 오답 문항을 재출제하고, 나머지 문항은 아직 풀지 않은 새로운 문항으로 구성한다.
- 3단계는 2단계의 오답 문항을 재출제하고 나머지는 새로운 문항으로 구성한다.
- 4단계도 동일한 규칙을 적용한다.
- 이전 단계 오답 재출제 수가 다음 단계 30문항을 초과하면, 오답 우선순위(최근 오답/반복 오답)를 적용해 30문항으로 제한하고 나머지 오답은 오답 복습 목록에 유지한다.
- 이전 단계 오답이 30문항 미만이면 새로운 문항으로 30문항을 채운다.
- 이미 응시한 새 문항은 다음 단계의 '새 문제'로 다시 배정하지 않는다. 단, 오답 재출제는 허용한다.
- 단계별 진행 상태와 결과는 기존 로컬 저장 방식에 맞춰 브라우저에 저장한다.
- 새로고침 후에도 잠금 해제와 응시 진행이 유지되어야 한다.

## 5. 결과 화면

각 단계 제출 후 표시:
- 점수 / 30문항
- 정답 수 / 오답 수
- 객관식·주관식 별도 정답률
- 틀린 문항 및 정답
- 기본 해설과 심화 해설
- 다음 단계 잠금 해제 상태

4단계 완료 후 전체 결과:
- 총 응시 문항 수 및 고유 문항 수
- 단계별 점수/정답률
- 반복해서 틀린 문항
- 국어 A/B 및 목차 범위별 취약 영역(문항 메타데이터가 충분한 경우)

## 6. XML 데이터 필드

기존 프로젝트 XML 형식을 유지하면서 시험용 루트와 문항 메타데이터를 확장한다.

필수 메타데이터:
- 시험 ID / 시험명
- 과목: 국어
- 학년: 중학교 2학년
- 학기: 2학기
- 시험 종류: 기말고사
- 교과서 구분: 국어 A 또는 국어 B
- 출처 범위: 페이지 및 관련 활동지
- 목차 기준 단원/소단원
- 난이도 및 통계 난이도
- 문항 ID / 유형 / 지문 / 보기
- 정답 / 허용 답안 / 채점 기준
- 해설 / 심화 해설
- 문제 푼 인원 / 정답 인원
- 문항 출처 권리·검수 상태

시험 진행 기록:
- 단계
- 문항 ID 목록
- 답안
- 정오 결과
- 제출 시각
- 단계 점수
- 오답 재출제 여부
- 잠금 해제 상태

## 7. 저작권 및 검수

- 교과서/활동지의 문항·지문을 그대로 복제하지 않는다.
- 사용자가 제공한 활동지는 범위와 학습 목표 확인에 활용하고, 생성 문항은 독립적으로 작성한다.
- 활동지에 제3자 저작물이 포함된 경우 상업적 이용 또는 재배포 가능 여부를 별도 확인한다.
- 문항 생성 후 정답, 오답 보기, 해설, 심화 해설을 검수한다.
- 검수 완료 문항만 시험에 노출한다.

## 8. 구현 순서

1. 상위 탭을 매일공부 / 시험으로 분리한다.
2. 시험 목록과 4단계 잠금 UI를 만든다.
3. XML 시험/문항 스키마와 로컬 진행 저장을 구현한다.
4. 단계별 오답 재출제 및 신규 문항 선택 로직을 구현한다.
5. 150문항 XML을 작성하고 자동 검증한다.
6. 단계 잠금, 새로고침 복원, 중복 배정, 오답 재출제를 테스트한다.

## 9. 문항 데이터 생성에 필요한 자료

실제 150문항을 정확히 생성하려면 다음 자료가 필요하다.

- 국어 A 166~199쪽 사진/PDF 또는 해당 단원명과 활동지
- 국어 B 70~119쪽 사진/PDF 또는 해당 단원명과 활동지
- 국어 B의 출판사/저자 또는 교과서 표지
- 관련 활동지 전체

자료가 확보되기 전에는 임의로 교과서 페이지의 단원과 내용을 추정해 문항을 만들지 않는다.
