# 2026-11-26 1차 국어 시험 문제은행 전면 개편

## 배경
기존 1차 시험은 지문·자료 없이 개념 설명을 반복하는 문항으로 구성되어 실제 시험 대비에 적합하지 않았다. 시험 화면도 회차 문항에 연결된 공통 지문을 출력하지 않았다.

## 반영 범위
- 중학교 2학년 2학기 국어
- B: 교과서 70~119쪽
  - 글과 자료 평가하며 읽기(70~87쪽)
  - 복합양식 자료를 활용하여 글 쓰기(88~119쪽)
- A: 교과서 166~199쪽
  - 점검하고 조정하며 읽기(166~187쪽)
  - 현실을 재현하는 매체 자료(188~199쪽)
- 120~165쪽은 출제 범위에서 제외
- 교과서의 학습 개념과 활동을 토대로 자체 재구성한 짧은 자료를 사용하고, 교과서 본문 장문을 그대로 복제하지 않음.

## 1차 문항 개편
- 1차 30문항을 전면 교체
- 객관식 25문항, 단답형 5문항
- 공통 자료 6세트 추가: 조사 결과, 추상화 설명, 읽기 상황, 축제 홍보물 비교, 온라인 게시글/카드뉴스, 복합양식 글쓰기 계획
- 문항별 지문 연결은 `passageRef`로 지정
- 문항별 정답, 기본 해설, 오답별 심화해설, 난이도, 범위, 응시·정답 통계 필드 유지
- 단답형은 `modelAnswer`, `scoringCriteria`를 추가하고 시험 화면에 모범 답안과 채점 기준을 표시
- 통계는 초기값 0, 정답률/난이도2는 응시 통계가 쌓이기 전까지 미산정

## 화면 수정
- 회차 시험 렌더러가 XML의 `passageRef`를 읽어 공통 자료를 표시하도록 수정
- 단답형 입력 영역에 모범 답안과 채점 기준 표시
- 1차 문항을 단원별로 고르게 뽑되, 특정 단원의 문항 수가 부족하면 나머지 단원의 미선택 문항으로 30개를 채우도록 보완
- FINAL 시험 XML과 화면 흐름은 별도 유지

## 검증 체크
- 전체 문제은행 150문항 유지
- 1차 교체 문항 30개
- 1차 객관식 25개 / 단답형 5개
- 공통 자료 6개 / 지문 연결 30개
- 전체 문항에 기본 해설·심화해설·통계 요소 존재
- 실제 모바일 브라우저에서의 렌더링과 풀이 동작은 사용자 기기에서 최종 확인 필요
