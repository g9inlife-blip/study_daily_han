# 2026-11-26 중2-2 국어 기말 문제은행 원문 대조 및 출제 기준

## 작업 목적
기존 문제은행을 실제 교과서의 지문·도표·학습 활동에 근거한 시험 대비 문항으로 개선한다.

## 확인한 자료와 한계
- 저장소의 시험 범위 파일: `docs/교과서/중학교국어(민)2-2_기말시험범위.pdf`
- 대화에 업로드되어 있던 교과서 원본: `중학교 국어(민) 2-2 교과서 PDF_펼침면.pdf`
- 교과서 원본 PDF는 텍스트 추출을 통해 본문과 활동 내용을 확인했다.
- 시험 범위 PDF는 GitHub 경로·파일명·바이너리 SHA(`15573e27400785a1faa3c99b362d5f3c914354b8`)까지 확인했으나, 현재 GitHub 연결 기능이 바이너리 본문을 반환하지 않아 그 파일에 표시된 정확한 범위 표기 자체는 읽지 못했다.
- 따라서 아래 페이지 구간은 기존 XML의 `sourcePages`와 문항별 `scopePages`에 기록된 범위를 기준으로 한 잠정 구간이며, 시험 범위 PDF 원문과 대조 완료한 것으로 간주하지 않는다.

## 교과서에서 직접 확인한 단원 및 학습 내용

### 1. 글과 자료 평가하며 읽기 (교과서 70쪽부터)
- 복합양식 자료의 내용 타당성, 신뢰성, 표현 방법의 적절성 평가
- 본문 「엠비티아이(MBTI)는 과학? 과몰입은 이제 그만!」
- MBTI 네 가지 지표(E/I, S/N, T/F, J/P)와 16개 유형을 설명하는 도표
- 중학교 학생 120명 설문 결과(흥미 이유: 자기 성격 이해 48%, 타인 성격 파악 30%, 친구들 사이 유행 19%, 기타 3%)
- MBTI 검사 결과를 절대화할 수 없는 이유, 검사 문항·응답 상황의 한계, 유형에 따른 편견과 오해
- 글쓴이의 관점과 의도, 근거의 타당성, 정보 제공자 및 자료 출처의 신뢰성 평가

### 2. 복합양식 자료를 활용하여 글 쓰기 (교과서 88쪽부터)
- 글·사진·도표·영상 등 복합양식 자료의 역할과 상호 보완 관계
- 주제·목적·예상 독자 등 쓰기 맥락 고려
- 자료 수집 및 선정, 자료의 출처·정확성 확인
- 글과 시각 자료의 배치, 문구와 이미지의 적절성
- 초고 작성 후 내용·표현·자료 활용을 점검하고 고쳐 쓰기
- 평가 기준에 따라 결과물을 검토하고 수정하기

### 3. 점검하고 조정하며 읽기 (교과서 166쪽부터)
- 본문 「추상화는 낙서가 아니야」(김영숙)
- 읽기 전: 읽기 목적 정하기, 수준에 맞는 글 선정하기, 배경지식 활성화, 예측하기
- 읽기 중: 독서 환경 확인, 예측한 내용 확인, 질문하기, 질문의 답 찾기, 모르는 단어·구절의 뜻 찾기, 메모, 다시 읽기, 자료 활용, 추론
- 읽기 후: 요약하기, 주제 파악하기, 감상하기, 읽기 활동 평가, 더 알아보고 싶은 내용 찾기
- 읽기 과정에서 생긴 어려움에 따라 전략을 선택·변경하는 점검과 조정

### 4. 현실을 재현하는 매체 자료 (교과서 188쪽부터)
- 재현: 현실의 대상이나 현상을 매체를 통해 나타내는 것
- 매체 자료는 현실을 그대로 복사하는 것이 아니라 제작자의 의도와 관점이 반영된 재현물
- 제작자는 제한된 지면·시간 안에서 장면·정보·표현을 선택하거나 배제함
- SNS 게시물의 장면 선택과 현실 인식
- 학생 수 감소를 다룬 두 뉴스의 관점·내용·표현 비교
- 광고·홍보물의 문구와 이미지 분석
- 성별·가족 등 특정 집단에 대한 고정 관념과 그 영향 분석

## 기존 문제은행 구조 확인
- 파일: `drafts/question-bank/중2_2학기_국어_기말_문제은행_150문항.xml`
- 전체 150문항
- 1~4차 각 30문항, 예비문항 30문항
- 전체 유형: 객관식 125문항, 단답형 25문항
- XML의 최상위 범위 속성: `sourcePages="70-119,166-199"`
- 기존 문항 중 일부는 교과서 본문과 직접 연결되지 않는 임의 재구성 지문 또는 정의 반복형 문항이므로 실제 시험 대비용으로 개선할 필요가 있다.

## 문제 제작 원칙
1. 시험 범위 PDF의 정확한 범위가 확인되면 해당 범위 밖의 단원·쪽수는 출제하지 않는다.
2. 교과서 본문과 학습 활동의 핵심 정보·자료·개념을 출제 근거로 삼는다.
3. 교과서 문장을 그대로 길게 복제하지 않고, 필요한 경우 학습 내용을 바탕으로 새 자료·상황을 구성한다.
4. 단순 용어 암기보다 도표·자료 해석, 근거 평가, 관점 비교, 읽기 전략 적용, 매체 재현 분석, 오답 판단을 중심으로 출제한다.
5. 각 회차는 객관식 25문항과 단답형 5문항을 유지한다.
6. 난이도는 문항의 추론 단계와 자료 복합성에 따라 하·중·상으로 설정한다.
7. 모든 문항에 과목·학교급·학년·범위·난이도·난이도2·문제·정답·해설·심화해설·응시 인원·정답 인원 필드를 유지한다.
8. 난이도2와 정답률은 응시 통계가 쌓이기 전까지 미산정으로 둔다.
9. FINAL 및 회차 해금·오답 재출제 로직은 별도 요청 없이 변경하지 않는다.
